# Object Watercolor

将照片中的同一主体、同一动作和同一情境，转译为小幅、稚拙、概括的抽象手绘。默认输出 1:1；用户指定其他比例或数量时，遵循用户要求。多张内容照片且未指定数量时，每张各生成一幅。

## 参考图的角色

- **新照片是主体与内容参考。** 保留主体身份、品种或外观特征，以及原本的姿势、动作、表情、情绪。保留主要物体、必要的场景线索、空间关系和叙事情境。
- **用户提供或确认的图片 A 只是风格与设计逻辑参考。** 可以借鉴概括程度、笔触、配色克制、纸张质感与留白逻辑，不复制 A 的具体行为、场景、道具、文字或构图细节。
- 没有图片 A 时，按下述文字风格生成。不要把其他照片或之前生成的画面自行当作内容来源。

## 固定视觉逻辑

- 主体与必要的场景线索聚成一幅小小的插画，四周保留大面积空白。不要让插画撑满画布。
- 只保留最明显的轮廓、关键颜色、姿势和情绪。用少量粗糙水彩色块、蜡笔线条和不规则手工笔触组织画面，允许断线、缺口和略笨拙的形状。
- 使用米白色旧纸张、轻微纸张颗粒、低饱和自然配色。通过简略形状和色块表现柔软或重量，不描摹照片中的毛发、织物或表面纹理。
- 人物、动物和物体都按各自识别特征概括；不要将所有主体套成同一种脸、轮廓或姿态。五官和小细节应简略，但仍能读出原本的表情与动作。
- 背景和道具只画足以说明关系的色块与线索，不精细复刻整个房间或场景。不要为了“旅行手账”氛围凭空添加行李、邮戳、贴纸或其他物件。
- 画面像宠物旅行手账、记忆速写或文艺明信片：稚拙、安静、概括、抽象。避免精致插画、写实水彩、3D 卡通、光滑矢量图形或照片滤镜。
- 默认不添加标题或装饰文字；用户要求文字时再加入。不要套用参考图 A 中的文字。

## 生成与检查

使用可用的图像生成工具。向工具明确标注每张图是“主体与内容参考”还是“风格参考”，并在提示词中简述当前照片的关键姿势、情绪、物体和空间关系。

生成后检查主体身份、动作与遮挡关系是否正确，场景是否仍是原来的情境，以及插画是否足够小、留白是否充足、颜色和纸张颗粒是否克制。

如果结果像精致水彩画或照片滤镜，减少轮廓内部细节和明暗塑形，改用更少、更松散的色块与蜡笔线；如果画面过满，缩小整个插画组。调整风格时，继续保留照片中的姿势、情绪与关键关系。不要用固定笔触数量或统一占幅比例取代视觉判断。
